# Magic & Mayhem HD

A widescreen patch for *Magic & Mayhem* (魔法师传奇). It runs the original, unmodified `Chaos.exe`; a replacement `ddraw.dll` patches the game in memory at startup.

- The battlefield renders at true widescreen resolution (default 1920x1080, scaled to your monitor).
- Menus stay at 800x600 and are scaled up.
- The battle minimap is drawn at 2x and anchored top-right.
- Fixes the original game's "No place to put wizard" error in quick battle.

This repo does **not** contain the game. You need your own copy.

## Install

1. Install or copy the game from your own disc.
2. Copy into the game folder (next to `Chaos.exe`):
   - `game/ddraw.dll`
   - `game/ddraw.ini`
   - `game/CFG/prefs.cfg` (optional: sets the frame rate to 32, see below)
   - `game/Sounds/Sounds.ini` (optional: fixes a `Sound Manger Load Error` for `Picview2.wav`)
3. Run `Chaos.exe`.

## Settings (`ddraw.ini`)

| Key | Meaning |
| --- | --- |
| `width`, `height` | Window client size. `0 0` = borderless fullscreen on the whole monitor. |
| `renderw`, `renderh` | Size the game renders at before scaling. Smaller = larger HUD and text, less map on screen. `1920 1080` = HUD x1.33 on a 1440p monitor, `1280 720` = HUD x2, `0 0` = native. |
| `log`, `dump`, `script` | Debugging aids; leave at 0. |

## Game speed

Battle logic is tied to the frame rate, so `MaxFramesPerSec` in `CFG/prefs.cfg` sets the game speed. The included `prefs.cfg` uses 32. The in-game options screen only offers 14/17/20 and overwrites this value if you change it there.

## Known limitations

- Videos are off (`PlayFMV=FALSE`): they use Indeo 4/5, which has no decoder on Windows 11.
- No music: the game plays music as CD audio tracks.
- Not yet tested: borderless fullscreen, spell casting, the campaign beyond the start of region 2, and the minimap on 100x100 maps.

## Building

The DLL is built with a 32-bit MinGW toolchain (e.g. llvm-mingw):

```sh
CC=/path/to/i686-w64-mingw32-gcc sh src/ddraw/build.sh
```

This writes `game/ddraw.dll`.

`src/ddraw/patches.h` is generated by `tools/gen_patches.py` from a capstone disassembly listing of `Chaos.exe`:

```sh
python tools/gen_patches.py chaos_listing.txt src/ddraw/patches.h
```

## Layout

- `src/ddraw/ddraw.c`: the DirectDraw wrapper and in-memory patches
- `src/ddraw/patches.h`: generated table of screen-size immediates
- `tools/gen_patches.py`: generator for `patches.h`
- `game/`: the built DLL and the edited config files
